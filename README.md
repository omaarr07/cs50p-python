# 🐍 CS50P: Harvard's Introduction to Programming with Python

This repository contains my problem sets, lab exercises, and notes while completing Harvard University's **CS50P (Introduction to Programming with Python)** course.

The goal of this course is to solidify my core Python syntax, algorithm design, object-oriented programming, and software testing fundamentals before building large-scale full-stack web applications.

---

## 📚 Course Progress & Topics Covered

- [x] **Week 0: Functions & Variables** — Arguments, return values, parameters, string formatting, basic math operations.
- [ ] **Week 1: Conditionals** — If/elif/else statements, Boolean logic, match statements.
- [ ] **Week 2: Loops** — `while` and `for` loops, lists, dictionaries, list iteration.
- [ ] **Week 3: Exceptions** — Handling errors, `try`/`except`/`else`/`finally` blocks, user input validation.
- [ ] **Week 4: Libraries** — Built-in modules (`random`, `sys`, `statistics`), third-party packages (`pip`), APIs, and JSON.
- [ ] **Week 5: Unit Tests** — Automated testing using `pytest`, assertions, and unit test design.
- [ ] **Week 6: File I/O** — Reading, writing, and parsing text, CSV, and binary files.
- [ ] **Week 7: Regular Expressions** — Pattern matching, extraction, and validation with `re`.
- [ ] **Week 8: Object-Oriented Programming (OOP)** — Classes, objects, methods, `@property`, getters/setters, operator overloading.
- [ ] **Week 9: Et Cetera** — Generators, list comprehensions, `map`, `filter`, and advanced Python features.
